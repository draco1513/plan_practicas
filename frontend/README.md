# ESFX TaskFlow — Frontend

React 18 · TypeScript · Vite · Bootstrap 5.

```
npm install
npm start          # inicia el front en http://localhost:5173  (redirige /api a http://localhost:8085)
npm run dev        # lo mismo que npm start
npm run build      # compila: comprueba tipos y genera dist/
```

Abre esta carpeta en VS Code. Si el backend está en otra dirección, copia `.env.example` a `.env` y cambia `VITE_PROXY_TARGET`.
